# NAP — its time to take one :) 🛋️✨

A colorful, vibrant, and interactive web platform built according to the **NAP Media** blueprint specification.

---

## 🎨 Creative Theme & Aesthetic
- **Vibrant Pop Aesthetic**: Soft neon gradients, pastel yellow, coral peach, electric mint, lavender, and crisp obsidian neobrutalist borders (`border-3`, `shadow-pop`).
- **Interactive Ambient Audio**: Web Audio API ambient chord generator for relaxing lo-fi background tones.
- **Dynamic Elements**: Confetti celebrations, real-time Napper Pass generator, RSVP modals, interactive quiz, and audio waveform simulation.

---

## 📑 Structure According to `Nap Media.pdf`

### 1. Page 1 — Sleep Over
*Covers community and experience-driven activities:*
- **Nap-O-Casting**: Relaxed, couch-based open-mic, audio storytelling circles, and cozy talent discovery without audition pressure.
- **Breakfast Castle**: Morning gastronomic sanctuaries with buttermilk pancake towers, artisan brews, rooftop sunshine, and unhurried conversations.
- **Pillow Fight**: Safe, cathartic community pillow fight tournaments — the ultimate urban stress-buster.

### 2. Page 2 — Image Management
*Focuses on brand consulting and PR services:*
- **Counsellor**: Brand therapy, crisis navigation, and 1-on-1 strategic narrative guidance for founders and creators.
- **Event Curation**: Immersive pop-ups, cozy brand lounges, and experiential product launches.
- **What-an-idea Promotion**: Bold guerrilla marketing stunts, internet culture activations, and earned-media viral PR hooks.
- **Brand Image Building**: End-to-end visual identity, tone-of-voice playbooks, and enduring cultural positioning.
- *Includes an interactive Project Brief submission modal.*

### 3. Page 3 — Nap Media
*The media/content wing:*
- **A Alap**: Signature intimate musical & conversational series where creators, thinkers, and musicians share unfiltered stories.
- Features an interactive audio waveform player with episode browser, guest roster, and track playback.

### 4. Front-Page / Bottom Modules
- **Upcoming Specials**: Featured spotlight entry for actor/creator **Amol Parashar** (*TVF Tripling*, *Sardar Udham*), with session details, interactive seat reservations, and teaser player.
- **Community CTA ("Become a napper")**: Call-to-action block revised from *"Be a Volunteer"* to *"Become a napper"*, featuring a real-time **Digital Napper ID Generator**, role selector, and confetti celebration.
- **Interactive "Nap Persona Quiz"**: A quick 3-question quiz helping visitors discover which NAP wing fits their vibe best.

## 🚀 Running Locally

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

---

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Audio**: Web Audio API synthesizer
